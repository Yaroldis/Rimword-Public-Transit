# Направление подъезда остановок (0.5.0-dev)

## Правило

Координата нижней стороны (по умолчанию) — **юг карты**, то есть `z - 1`. При повороте самой остановки используется стандартный `Rot4` RimWorld; отдельно сохранять направление не нужно.

| Поворот | Подъезд относительно остановки | Клетка-маркер |
| --- | --- | --- |
| South | снизу | `(x, z - 1)` |
| East | справа | `(x + 1, z)` |
| North | сверху | `(x, z + 1)` |
| West | слева | `(x - 1, z)` |

Маркер рисуется голубым контуром **при выборе остановки** и не занимает клетку как объект. Он обозначает пассажирскую сторону дороги.

## Для крупного транспорта

Машина может занимать несколько клеток, поэтому её **центр** не должен приходиться на маркер. Вместо этого маркер находится у края корпуса, а машина целиком располагается по нужную сторону от знака. Парковочное положение выбирается детерминированно и преимущественно по выравниванию корпуса с остановкой.

Если клетка заблокирована или автомобиль целиком не помещается на нужной стороне, маршрут не выбирает другую сторону. Появляется предупреждение о невозможности парковки.

## Поворот

- Пока строится: Q/E (стандартное вращение RimWorld), стартовое направление South.
- После строительства: кнопка **«Повернуть сторону подъезда»** (поворот на 90° по часовой стрелке).
- При повороте уже используемой остановки линии через неё останавливаются. Сами определения линий, назначения машин и водителей не теряются.
- Старые сохранения 0.4.3 при загрузке впервые получают направление South. Повторные загрузки сохраняют направление игрока.

## Для художника

Пока используются автоматически повёрнутые варианты прежнего спрайта:

- `Textures/Things/Building/TransitStop_south.png` — основной вид, указатель снизу;
- `.../TransitStop_east.png` — указатель справа;
- `.../TransitStop_north.png` — указатель сверху;
- `.../TransitStop_west.png` — указатель слева.

Все четыре — прозрачные PNG размером 128×128. Файл `TransitStop.png` остаётся для иконки в меню. В будущем художник может нарисовать другие виды, сохранив имена файлов.

## Что проверить в игре

Вместе с направлением подъезда нужно отдельно проверить, сохраняется ли нужный разворот машины после штатного задания VF `Goto`, особенно для длинного транспорта. Этот момент пока не подтверждён игровым тестом.
