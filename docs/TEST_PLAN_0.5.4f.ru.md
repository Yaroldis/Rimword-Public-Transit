# Public Transit 0.5.4f-dev — выбор достижимой точки парковки

Цель: проверить работу алгоритма **без принудительного запуска Job**.

Версии: RimWorld 1.6, Vehicle Framework 1.6.2144, VVE.

## Перед испытанием

- Сделать копию сохранения с треком `Inside → End → Start`.
- Установить новую DLL из успешного GitHub Actions.
- Не использовать откатанный патч 0.5.4b (`ClearQueuedJobs`/принудительный `StartJob`).
- Сохранить прежний состав модов, чтобы сравнение было корректным.

## Проверки

1. Запустить линию в прежнем проблемном положении. Убедиться, что в логе появился `[DockChoice]`, включая выбранную точку и `vfReachable=True`.
2. Провести минимум 5 полных кругов `Inside → End → Start`. Проверить, что нет повторной выдачи `Goto` в собственную клетку машины.
3. Изменить ориентацию остановки при строительстве: север / восток / юг / запад. Проверить выбор кандидата на стороне голубого маркера.
4. Проверить, что для автомобиля с длинным корпусом кандидат выбирается предпочтительно параллельно краю остановки (фактический разворот контролирует VF и может отличаться).
5. Сделать одну остановку заведомо недоступной для машины. Ожидаем понятную причину `no reachable full-size parking space` и отсутствие бесконечных повторов `Goto`.
6. Повторить на узком участке с возможностью объезда и убедиться, что VF находит достижимую точку, если она существует.
7. Проверить сохранение/загрузку в ходе поездки, работу водителя, его перерывы и управление зажиганием.
8. Проверить отсутствие `Traveller started 10 jobs in one tick`.

## Если появится новая ошибка

Прислать:

- сообщение `[DockChoice]` или `no reachable full-size parking space`;
- ближайшие `[ReachDiag]`, `[GotoDiag]`, `[JobTrace]` и `PatherFailed`, если они появились;
- расположение остановки (и направление синего маркера) на скриншоте.

**Ограничения:** VF `CanReachVehicle` — предварительная проверка регионов, а не гарантия, что полный асинхронный поиск пути завершится успешно. `Goto` не принимает обязательное конечное направление корпуса. Если все точки VF считает недостижимыми после стоянки, следующим шагом станет анализ формы стартовой позиции (с учётом корпуса и ориентации), а не повторный `StartJob`.
