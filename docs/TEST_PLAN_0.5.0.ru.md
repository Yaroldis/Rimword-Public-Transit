# Public Transit 0.5.0-dev — тест-план водителей

**Экспериментальная реализация.** Первый тест — только на копии сейва, RimWorld 1.6 + Vehicle Framework 1.6.2144 + Vanilla Vehicles Expanded. Работа автоматической посадки VF не подтверждена до тестирования в игре.

## Что изменено

- Можно выбрать одного конкретного колониста как водителя линии. Другой линии его назначить нельзя.
- Линия, у которой водитель назначен, едет только когда **именно этот колонист** занял водительское место.
- После запуска линии диспетчер каждые 250 тиков проверяет свободного назначенного колониста. Если он простаивает, выдаёт специальный `Job` для подхода к машине и посадки через VF.
- Экспериментальная автопосадка по умолчанию **выключена**. Её можно включить в настройках мода. Если на этом VF нет совместимого API автоматической посадки, задание безопасно прекращается с сообщением `[Public Transit] Could not board assigned driver`. Ручная посадка остаётся доступной.
- Без назначения водителя сохраняется **старый режим** 0.4.3: игрок вручную сажает пешку, и линия едет как раньше.
- Автоматического подбора других пешек, работы с приоритетами и пересменок **нет**.

## Сценарий проверки

1. После установки убедиться, что остановки и линии из сейва 0.4.3 сохранились.
2. В редакторе выбрать машину на линии и назначить конкретного свободного колониста в новой строке «Водитель».
3. Назначить этого же колониста на другую линию — должно появиться сообщение о конфликте.
4. В «Настройки → Моды → Public Transit» **включить экспериментальную автопосадку** (по умолчанию выключена). Оставить колониста свободным и нажать «Запустить линию». Он должен получить работу посадки и пойти к автомобилю.
5. Проверить, что колонист занимает **водительское** место, а не пассажирское. Машина начинает маршрут.
6. Если посадка не удалась, открыть лог, найти сообщение `[Public Transit] Could not board assigned driver` и отправить его целиком. Сам колонист должен остаться на карте, и машина не должна ехать без него.
7. Проверить, что с другим водителем за рулём машина **не поедет**, когда на линии назначена конкретная пешка.
8. Сохранить и загрузить сейв с назначенным водителем. Проверить сохранение назначения.
9. Снять назначение водителя; после этого снова работает ручная посадка, как в 0.4.3.
10. Проверить, что во время лечения/строительства/сна диспетчер не прерывает текущее задание выбранной пешки.
11. Проверить красные ошибки/предупреждения и осмотреть журнал после посадки и высадки.

## Особо важно

**Не проверено компиляцией локально:** у исполнителя нет .NET SDK и DLL из установленной игры. Первый этап — GitHub Actions CI; второй — испытание API VF в игре. Если посадка через VF не работает, исправляем адаптер по фактической сигнатуре API, а не перемещаем пешку напрямую.

## Направленный подъезд (добавлено в тот же релиз 0.5.0-dev)

12. На новой остановке по умолчанию точка подъезда должна находиться **снизу (к югу)** — выдели остановку, клетка подсветится голубым.
13. Поверни новую остановку при строительстве на четыре стороны. Подсветка и нижняя часть знака должны менять направление: юг → запад/восток → север по выбранному повороту.
14. На **уже построенной** остановке нажми «Повернуть сторону подъезда» четыре раза. Маркер должен последовательно пройти четыре соседние клетки и вернуться обратно.
15. Создай маршрут с двумя/тремя остановками, у которых разные направления. Машина должна останавливаться корпусом у **подсвеченной** стороны каждой остановки, а не с любой удобной стороны.
16. Проверь габаритную машину (например, 2×3): нельзя считать прибытием, если её корпус соприкасается с остановкой с неправильной стороны.
17. Заблокируй всё пространство со стороны подъезда (другой VF-машиной или препятствием). Линия должна отказаться от парковки вместо смены стороны.
18. Поверни остановку при **активной** линии: линия должна выключиться; назначения машины/водителя и список остановок не должны потеряться.
19. Сохрани/загрузи игру с повёрнутой остановкой. Направление и подсвеченная клетка должны сохраниться.
20. Открой старый сейв 0.4.3: раньше неповорачиваемые остановки после обновления получают южную сторону по умолчанию.

**Важно:** подсвеченная точка — это логический ориентир, а не отдельная постройка. Дорожное движение по-прежнему обеспечивает VF. Если нет подходящего места для корпуса автомобиля на выбранной стороне, линия не должна молча парковаться на другой.
