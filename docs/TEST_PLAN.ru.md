# Проверка исправления 0.3.1-dev (RimWorld 1.6)

Сделайте **копию сохранения 0.3.0** перед обновлением. Автоматическая езда всё ещё отсутствует.

## В чём изменения

1. На линию можно назначать **ведущий транспорт**: обычные автомобили и локомотивы Trains of the Rim. Одиночные вагоны больше не должны быть доступны в меню.
2. VF хранит отдельную прочность каждого компонента. В «Настройки → Моды → Public Transit» задаётся порог **процента потерянной прочности одного компонента**, по умолчанию 50%. При достижении порога назначение снимается не позднее 250 игровых тиков. Сама машина остаётся ремонтопригодной.
3. Слишком повреждённую машину нельзя назначить вручную до ремонта. При недоступности API здоровья мод выводит **одно предупреждение** в лог и не снимает машину по ошибке.

## Чек-лист

- [ ] Существующие остановки, линии и назначенные здоровые машины пережили обновление и перезагрузку сейва.
- [ ] Локомотив Trains of the Rim предлагается в выборе; **каждый тип вагона** не предлагается.
- [ ] Машины Vanilla Vehicles Expanded предлагаются как раньше.
- [ ] Порог по умолчанию в настройках равен 50%, его можно изменить.
- [ ] При 49% повреждения отдельного компонента машина остаётся назначенной.
- [ ] При 50% или более повреждения **любого** компонента машина автоматически освобождает маршрут через ≤250 тиков; появляется сообщение.
- [ ] Машина при снятии не исчезает с карты, продолжает подлежать ремонту.
- [ ] Пока машина не отремонтирована ниже порога, повторное назначение невозможно.
- [ ] После ремонта машину можно назначить повторно; назначение переживает сохранение/загрузку.
- [ ] Если машина физически удалена / действительно Destroyed, ссылка очищается; когда она временно вне карты, назначение сохраняется.
- [ ] Прочие линии не теряют назначение при повреждении машины на другой линии.
- [ ] Нет новых красных ошибок и лавины жёлтых предупреждений в журнале.

## Если локомотив не распознался

Напишите его название, `defName` (если известно), приведите скриншот списка назначения и файл `Player.log`. Определение ведущего транспорта пока специально консервативное: неизвестный объект Trains of the Rim **не допускается**, пока его не классифицируем.

## Если проверка здоровья не сработала

Найдите в логе `[Public Transit] Cannot read Vehicle Framework component health` и пришлите полный текст одной строки. Логика при несовместимом VF API намеренно не делает автоматическое снятие по предположительным данным.
