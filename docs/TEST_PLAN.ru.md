# Проверка Public Transit 0.3.0-dev (RimWorld 1.6)

## Что изменилось

В редакторе каждой линии теперь можно выбрать машину из модов, использующих Vehicle Framework, изменить или снять назначение. Машина пока **не движется автоматически**, пассажиры не садятся, вместимость не проверяется. Назначение — связь «одна конкретная машина ↔ одна конкретная линия».

Для тестов подойдут **Vanilla Vehicles Expanded** и **Trains of the Rim**. Используйте машины, реально размещённые на карте, принадлежащие колонии. Для поездов на этой стадии проверяется распознавание отдельных транспортных объектов, а не движение состава по рельсам.

## Обновление

1. Сохраните **копию** тестового сейва 0.2.0.
2. Отправьте патч 0.3.0 в GitHub. Workflow `CI (RimWorld 1.6)` должен пройти без ошибок.
3. Скачайте ZIP артефакта `PublicTransit-1.6-ci`; внутри должна быть папка `PublicTransit/` с DLL в `1.6/Assemblies/`.
4. Замените папку старой версии мода (не сохраняйте две копии с одинаковым packageId).
5. Проверьте порядок загрузки: Harmony → Vehicle Framework → транспортные моды → Public Transit. Нужная версия игры — 1.6.

## Основные проверки

- [ ] **Обратная совместимость.** Загрузите сохранение 0.2.0. Имена остановок и порядок линий не изменились, транспорт в старых линиях показан как «не назначен».
- [ ] **Распознавание VVE.** Разместите на карте собственную машину Vanilla Vehicles Expanded; откройте редактор маршрутов → «Назначить». В списке должна быть машина с координатами.
- [ ] **Распознавание Trains of the Rim.** Разместите транспорт этого мода; он должен появиться в меню назначения, если его игровой тип наследует `Vehicles.VehiclePawn`.
- [ ] **Защита от чужого транспорта.** Техника фракций NPC не должна предлагаться для назначения.
- [ ] **Назначение.** Назначьте первую машину линии №1; машина отображается в строке «Транспорт», статус сообщает, что движение ещё не реализовано.
- [ ] **Уникальность.** Создайте вторую линию и откройте её назначение: первая машина недоступна (уже закреплена за линией №1).
- [ ] **Переназначение.** При наличии второй машины нажмите «Сменить» в линии №1. Вторая машина назначается, первая освобождается.
- [ ] **Снятие.** Нажмите «Снять»; машина становится доступна на другой линии.
- [ ] **Сохранение/загрузка.** Назначьте машину, сохраните игру, полностью загрузите этот сейв; должно сохраниться назначение конкретного объекта, а не только название модели.
- [ ] **Уничтожение.** Уничтожьте назначенную машину игровыми средствами, подождите примерно 250 игровых тиков; назначение должно очиститься автоматически, без ошибок.
- [ ] **Удаление линии.** Удалите линию с назначенной машиной; техника остаётся на карте и доступна другим линиям.
- [ ] **Удаление остановки.** Разрушьте остановку из линии: она удаляется, назначение транспорта не пропадает; если осталось меньше двух остановок, статус сообщает об этом.
- [ ] **Отсутствие техники.** Если на карте нет свободного транспорта, кнопка «Назначить» сообщает об этом, не создавая ошибок в журнале.

## Что не проверяем на 0.3.0

- Наличие свободных пассажирских мест и подходящего водительского места.
- Возможность добраться от одной остановки до другой; для поездов — конфигурацию рельсов, локомотивов и вагонов.
- Движение, посадку, высадку, топливо, пассажирский ИИ.

## Если возникнет ошибка

Пришлите: скриншот редактора линии; текст первой красной ошибки и её stack trace; название машины и мода; действие перед ошибкой. Ошибка именно компиляции — приложите лог шага `Compile mod (net472)` из GitHub Actions.
