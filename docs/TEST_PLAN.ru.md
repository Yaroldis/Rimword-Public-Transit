# Проверка 0.2.0-dev в RimWorld 1.6

**Это тестовая версия редактора линий.** Автобусы не ездят, пешки не садятся в транспорт.

## Установка сборки из CI

1. Отправить изменения на GitHub и дождаться успешного workflow `CI (RimWorld 1.6)`.
2. Скачать артефакт `PublicTransit-1.6-ci`. В отличие от старого workflow, ZIP артефакта теперь содержит сразу каталог `PublicTransit/` (без второго ZIP внутри).
3. Извлечь каталог в `<RimWorld>/Mods/PublicTransit/` и заменить старые файлы.
4. Запустить игру 1.6 с Harmony, Vehicle Framework и Public Transit. Дополнительный транспортный мод для этой стадии не требуется.
5. Начать с **копии** тестового сохранения: мод ещё экспериментальный.

## Ручные проверки

- [ ] **Запуск.** В журнале `[Public Transit] Bootstrap loaded for RimWorld 1.6.` и нет новых красных ошибок с `[PublicTransit]`.
- [ ] **Остановки.** Построить 3 остановки. Выбрать первую. Доступны кнопки «Создать линию», «Назвать остановку», «Транспортная сеть».
- [ ] **Название.** Назвать остановки «Жильё», «Завод», «Больница». Убедиться, что имя видно в информации об остановке и меню добавления.
- [ ] **Создание.** На остановке «Жильё» нажать «Создать линию», назвать «Линия 1»; убедиться, что она включает «Жильё».
- [ ] **Дополнение.** В «Транспортной сети» добавить «Завод» и «Больницу». Повторное добавление одной остановки в одну линию не предлагается.
- [ ] **Порядок.** Кнопками ↑/↓ переставить остановки в последовательность «Жильё → Больница → Завод».
- [ ] **Переименовать линию.** Изменить название на «Экспресс». Убедиться, что оно меняется.
- [ ] **Сохранить/загрузить.** Сохранить игру, выйти в меню, загрузить. Названия остановок, линия и её порядок должны сохраниться.
- [ ] **Удалить постройку.** Снести «Больницу»: остановка должна исчезнуть из списка и из всех линий, без ошибок в журнале.
- [ ] **Удалить из линии.** Нажать «Убрать» рядом с «Завод». Постройка должна остаться на карте.
- [ ] **Удалить линию.** Нажать «Удалить», подтвердить. Убедиться, что остановки остались.
- [ ] **Старая игра.** Загрузить сейв от 0.1.0 с одной остановкой и проверить, что она по-прежнему работает.

## Если появятся ошибки

Пришли первые строки красной ошибки + развёрнутый stack trace, а также укажи действие (создание линии, загрузка, удаление остановки). Жёлтые ошибки перевода и `tradeAdj_fem` из прошлой проверки могли относиться к другим модам — если они повторяются без Public Transit, это отдельная проблема.
