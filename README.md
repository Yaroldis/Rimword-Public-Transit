Мод для будущей автоматической сети общественного транспорта. На текущем этапе реализованы **остановки, линии и назначение транспорта,движения машин, водительский ИИ**, но пока нет пассажирского ИИ и расписаний. Ведущая техника берётся из модов, основанных на [Vehicle Framework](https://github.com/SmashPhil/Vehicle-Framework).
